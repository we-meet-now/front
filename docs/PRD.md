## 1. 제품 개요

**위밋톡**은 모임을 더 스마트하게 만들어주는 AI 채팅앱이다.

일정 조율, 장소 선정, 정산까지 모임의 전 과정을 하나의 채팅방 안에서 AI 매니저와 함께 처리할 수 있도록 한다.

**참고 서비스**
- **Partiful**: 링크(초대장)로 모임 전용 공간에 접근하는 구조
- **셋로그**: 초대코드 기반 입장 방식
- **Doodle / Calendly / When2Meet**: 일정 조율 서비스 (위밋톡의 캘린더는 독자적인 방식으로 구현)
- **네이버 밴드 / 소모임**: 모임 구성원 연결 서비스

**출시 계획**
- 1차: Web 출시 (현재 MVP)
- 2차: Android 앱 (Play Store) 출시

## 2. 목표 사용자

| 그룹 | 모임 맥락 |
|---|---|
| 대학생 | 팀플, 대외활동, 동아리 — 각지에서 모여야 하는 상황 |
| 20대 후반 ~ 30대 초중반 | 커뮤니티, 교육 세션, 스터디 — 자기개발 목적의 소규모 모임 |

**공통 페인포인트**
- 중요한 일정을 수행하기 위해 일정을 조율하는 과정 자체가 피로하게 느껴진다
- 모임이 끝난 뒤 정산을 개별로 진행해야 하는 불편함

## 3. 경쟁 구도

```
소모임 / 네이버 밴드     →  구성원 연결에 집중, 조율 기능 부족
Doodle / When2Meet      →  일정 조율 특화, 채팅·장소·정산 없음
카카오톡                →  범용 메신저, 모임 특화 기능 부족
위밋톡                  →  모임 전 과정을 AI와 함께 처리하는 모임 특화 채팅앱
```

## 4. 핵심 기능

### 4-0. 비로그인 모임장소 추천 (게스트 기능)

회원가입 없이 바로 사용할 수 있는 라이트 기능으로, 서비스 진입 퍼널 역할을 한다.
랜딩 페이지의 "모임장소 추천받기" 버튼으로 진입하며, 두 가지 경로로 분기된다.

**경로 A — 모두에게 물어보기** (참여자에게 링크 공유)
1. 내 출발지 + 닉네임 입력 (상세주소는 비공개, 시·구까지만 공개)
2. 링크 생성 (7일간 유효) → 카카오톡/기타 앱으로 공유
3. 참여자들이 링크에서 각자 출발지 입력 → 실시간 입력 현황 지도 표시
4. 중간위치 자동 산출 → AI 장소 추천 (맛집/카페/문화생활 카테고리, 최대 3곳 선택)
5. 선택한 장소를 링크로 공유

**경로 B — 내가 직접 입력** (주최자가 모든 출발지 직접 입력)
1. 참여자 출발지를 최대 10명까지 직접 입력
2. 중간위치 계산 → 소요시간 비교 표시
3. AI 장소 추천 → 선택 후 공유

**게스트 기능 특징**
- 회원가입 불필요
- 닉네임은 "익명이", "토끼", "사자" 등 선택 또는 직접 입력
- 마지막 화면에서 위밋톡 채팅방(일정 조율·투표·정산) 전체 기능 가입 유도 CTA 노출

---

### 4-1. 초대코드 기반 채팅방 입장

- **주최자**: 회원가입 후 채팅방 생성 → 초대 링크(URL) 또는 초대코드 공유
- **참여자**: 두 가지 방법으로 입장 가능
  - 방법 A: 초대 URL을 그대로 복사하여 접속
  - 방법 B: 위밋톡 랜딩페이지에서 초대코드를 직접 입력하여 입장
- 참여자는 별도 회원가입 불필요

### 4-2. 모임 채팅방 생성

생성 시 장소/시간 확정 여부에 따라 두 케이스로 분기:

- **케이스 A — 이미 결정된 경우**: 날짜·시간·장소를 지정하고 시작
- **케이스 B — 논의가 필요한 경우**: 미정 상태로 채팅방을 열고 멤버들과 함께 조율

**생성 퍼널 (케이스 B 기준, 3단계)**
1. 시간 선택 (날짜·시간 입력)
2. 모임 유형 선택 (AI 자동 추천 또는 직접 입력)
3. 장소 결정 방식 선택 (AI 추천 / 투표 / 직접 검색)

### 4-3. 실시간 채팅

- STOMP WebSocket 기반 실시간 메시지 송수신 (백엔드 구현 완료)
- 메시지 타입: 일반 대화 / 시스템 알림 / AI 매니저 메시지 / 날짜 구분선
- 채팅방 내 탭으로 AI 매니저, 캘린더, 투표, 정산 화면 전환

### 4-4. AI 매니저

- **모임 진행 브리핑**: 모임 준비에 진척이 생길 때마다 AI 매니저가 채팅방에 상황 요약 메시지를 전송 (채팅 템플릿 사전 정의)
- **공평한 중간 지점 산출**: 참여자 위치를 입력받아 이동 거리가 균등한 중간 지점 자동 계산
- **AI 장소 추천**: 중간 지점 인근 장소 추천 (이름, 주소, 추천 이유 포함)
- **투표 연동**: 추천 장소를 투표 후보로 바로 추가 가능

### 4-5. 공유 캘린더 (일정 조율)

위밋톡 전용으로 설계한 캘린더 UI:
- 멤버별 가능 날짜를 달력에 점(dot)으로 표시
- 모두 가능한 날짜는 노란색 테두리로 강조
- 일정 확정 버튼으로 모임 날짜 확정
- (Doodle과 유사한 컨셉이지만, 위밋톡 모바일 환경에 맞게 독자적으로 구현)

### 4-6. 장소 투표

- AI 추천 장소 또는 직접 추가한 장소를 후보로 투표
- 실시간 투표 집계 표시

### 4-7. 알림

- 모임 홈(지도) 화면에서만 상단에 플로팅(floating) 형태로 표시

### 4-8. 모임비 정산 _(향후 오픈 예정)_

- 토스 API를 활용한 구현 예정
- 모임 후 비용 입력 → 멤버별 정산 금액 자동 계산 → 채팅방 내 공유
- 현재 MVP 단계에서는 미오픈

## 5. 화면 구조 (IA)

```
[인증 전]
/                          랜딩 (초대코드 입력 · 모임장소 추천 진입)
/login                     로그인
/register                  회원가입

[비로그인 게스트 플로우 — 회원가입 없이 사용]
/place                     모임장소 정하기 진입 (경로 A/B 분기)
  /share                   내 출발지 입력 + 링크 공유 (경로 A)
  /status                  출발지 입력 현황 실시간 확인 (경로 A)
  /result                  AI 장소 추천 + 공유 (A/B 공통)
  /direct                  주최자가 출발지 직접 입력 (경로 B)
  /midpoint                중간위치 결과 확인 (경로 B)

[인증 후 — GNB 5탭, 모임방 기준]
/meeting/:roomId/
  ├── home                 홈 — 지도 · 오늘 모임 · 출발 현황     [GNB 탭 1]
  ├── calendar             캘린더 (미오픈)                        [GNB 탭 2]
  ├── chat                 톡 — 채팅방 목록                       [GNB 탭 3]
  │     └── /room/:roomId/ 채팅방 상세 (채팅방 내부 탭)
  │           ├── chat          실시간 채팅
  │           ├── ai            AI 매니저
  │           ├── calendar      공유 캘린더
  │           ├── poll          장소 투표
  │           └── settlement    정산 (미오픈)
  ├── gallery              갤러리 (미오픈)                        [GNB 탭 4]
  └── mypage               마이페이지                             [GNB 탭 5]
        ├── detail               회원정보
        ├── notification-setting 알림 설정
        ├── calendar-setting     캘린더 설정
        ├── friend-setting       친구/채팅방 설정
        └── map                  지도 설정

[모임 생성]
/create-meeting            모임 생성 퍼널 (3단계)
```
