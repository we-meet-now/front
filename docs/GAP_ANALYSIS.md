## 0. 2026-08-10 대비 변경 사항

- **1-1 비로그인 장소추천 플로우**: `미구현` → **라우트·UI 구현 완료** (커밋 `46b095c`, `f479437`, 작성일 저녁 이후). `/place`, `/place/share`, `/place/status`, `/place/direct`, `/place/midpoint`, `/place/result`, `/place/share-complete` 전 화면 존재. 단 대부분 `sessionStorage` 상태 공유 + 하드코딩 mock(고정 링크, 고정 중간위치 "강남역"/"사당역", `setTimeout` 시뮬레이션)이고, 장소 추천(PC-12R/PC-23 해당 화면)만 `fetchSearchPlaces` 실제 API를 호출함(실패 시 하드코딩 3곳으로 폴백). 자세한 내용은 아래 1-1 참고.
- **신규 발견 — 랜딩 진입 버튼 없음**: `/place` 플로우 자체는 완성됐지만, 랜딩 페이지(`OnBoardingPage`)에 목업 LD-01의 "모임장소 추천받기" 버튼이 여전히 없어 URL을 직접 치지 않으면 도달할 수 없는 고아 라우트 상태. 1-3과 함께 봐야 함.
- 그 외 섹션(1-2, 1-3, 1-4, 1-5, 2-1~2-7, 3, 4)은 코드 재확인 결과 2026-08-10 작성 시점과 동일 — 변화 없음.

## 1. 미구현 — 목업에 있지만 코드에 없는 것

### 1-1. 비로그인 모임장소 추천 플로우 (PC-01 ~ PC-23) — ⚠️ 부분 구현됨 (2026-08-10 저녁 커밋)

목업의 랜딩(LD-01) 하단 "모임장소 추천받기" 버튼으로 진입하는 전체 게스트 플로우.
**라우트/화면 자체는 모두 구현되었으나, 랜딩에서 진입할 방법이 없고 대부분 mock 데이터로 동작한다.**

| 목업 화면 | 설명 | 구현 현황 |
|---|---|---|
| PC-01 | 진입 — 경로 A(모두에게 물어보기) / 경로 B(직접 입력) 분기 | ✅ `/place` (`GuestPlaceEntryPage`) |
| PC-11 | 경로 A — 내 출발지 + 닉네임 입력 | ✅ `/place/share` (입력 단계) |
| PC-11S | 경로 A — 링크 생성 + 카카오톡/기타 앱 공유 | ⚠️ `/place/share` (공유 단계) — 링크는 `wemeettalk.com/meet/abc123` 하드코딩, 카카오톡/다른 앱 공유 버튼은 동작 없음(클립보드 복사만 실제 동작) |
| PC-12 | 경로 A — 출발지 입력 현황 실시간 확인 + 지도 표시 | ⚠️ `/place/status` — 실시간 아님, "참여자 입력 시뮬레이션" 버튼으로 더미 2명만 순차 추가, 지도는 정적 mock |
| PC-12R | 경로 A — AI 장소 추천 (카테고리 필터, 최대 3곳 선택) | ✅ `/place/result?from=share` — `fetchSearchPlaces` 실제 API 연동(실패 시 하드코딩 폴백) |
| PC-13 | 공통 — 선택 장소 공유 + 위밋톡 가입 유도 CTA | ✅ `/place/share-complete` |
| PC-21 | 경로 B — 출발지 최대 10명 직접 입력 | ✅ `/place/direct` |
| PC-22 | 경로 B — 중간위치 결과 + 소요시간 비교 | ⚠️ `/place/midpoint` — 중간위치는 항상 "강남역" 하드코딩, `setTimeout(1800ms)`로 로딩만 흉내, 실제 계산 API 없음 |
| PC-23 | 경로 B — AI 장소 추천 | ✅ `/place/result?from=direct` — PC-12R과 동일 컴포넌트 공유 |

**목업과의 세부 차이**
- 닉네임 프리셋: 목업은 "익명이/토끼/사자" 3종, 코드는 "익명이/토끼/사자/곰돌이" 4종 (사소한 확장)
- 공유 링크 "7일 유효" 문구는 있으나 실제 만료 로직/백엔드 링크 발급 없음 — 전부 고정 문자열
- 출발지 "시·구까지만 공개" 정책 문구는 있으나 실제 주소 마스킹 로직 없음(입력값 그대로 저장)
- 카카오톡/다른 앱 공유 버튼: 목업은 `toast`로라도 피드백 있음, 코드는 클릭해도 아무 동작 없음(링크 복사 버튼만 실제 동작)

**신규 발견**
- 랜딩(`OnBoardingPage`, `src/pages/onboarding/index.tsx`)에 "모임장소 추천받기" 진입 버튼이 없어 `/place`로 가는 자연스러운 사용자 경로가 없음 (1-3 참고)

현재 코드: OnBoardingPage → StartPage 2단계 구조, "모임장소 추천받기" 없음, 초대코드 입력 동작 없음

## 4. API 연결 현황

| 기능 | 연결 여부 | 엔드포인트 |
